Sphaira

Sphaira's built-in Ownfoil menu browses your library by game: pick the version and DLC and it downloads only what it needs, whatever files they're in. Downloads resume after a dropped connection, and artwork comes from Homefoil, so your Switch never contacts Nintendo.

Sphaira file browser

{{ where('browser') }}

Mounts the shop as folders in Sphaira's file browser. Handles HTTPS, login, URL content filters, NSZ and XCZ. Titles come from its own data, which can differ from what Homefoil identified.

  1. In Sphaira, open Menu → Advanced Options, turn on Install options → Enable emummc, then open Add / modify mounts → Create New Entry.
  2. Enter these details, press Save and restart Sphaira.
  3. Open FileBrowser → Options → Mount and select {% if show_local_tab %}[HTTP] {{ shop_name }} - Local{% endif %}[HTTP] {{ shop_name }} - Remote.
